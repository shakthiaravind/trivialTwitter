# trivialTwitter

# Description
This project simulates a basic social media platform. It utilizes a client-server architecture to enable real-time text message exchange among multiple users. The server handles user authentication, message storage, and delivery. Users can post messages (tweets) and view others' posts (timeline). The system employs socket programming for communication and a simple data structure for message storage.

# Technologies used
Programming Language: **Python (3.9.6)**   
Server-side Handling: Multiple clients handled using select() from the **selectors** module.  
User Interface: GUI implemented using **tkinter** for improved user experience.
